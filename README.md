# Gau Rakshak AI

**AI-Based Early Mastitis Risk Monitoring & Raspberry Pi Voice Assistant**

Gau Rakshak AI is an AI-enabled dairy cattle health monitoring project developed by **Team RUDRAX** at **Geetanjali Institute of Technical Studies (GITS), Udaipur**.

The project combines a web-based cattle health monitoring platform with a Raspberry Pi-based offline voice assistant to support early mastitis risk monitoring and farmer assistance.

---

## 🌐 Web Application

The web application provides farmers and veterinarians with a simple interface to monitor cattle health and review AI-based mastitis risk information.

### Key Features

- Individual animal risk monitoring
- No Risk, Low Risk, Moderate Risk and High Risk categories
- 7–14 day mastitis risk forecasting
- Animal-wise health information
- Sensor-related health parameters
- Risk trends and visualizations
- Alerts for high-risk animals
- Action-oriented recommendations
- Farmer dashboard
- Veterinarian dashboard
- Multilingual interface support
- Responsive web interface

### Technology Stack

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Recharts
- Lucide React
- Firebase Authentication
